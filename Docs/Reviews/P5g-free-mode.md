# P5g 리뷰 기록

명세: [Docs/Specs/P5g-free-mode.md](../Specs/P5g-free-mode.md) · 브랜치: `codex/P5g-free-mode`

**Codex가 할 일:**
- 상태가 `열림`인 항목을 위에서부터 반영한다.
- 항목의 세 칸은 이렇게 다룬다:
  - **문제**는 반드시 해결한다.
  - **제안**은 권장이다. 다르게 하면 보고 ③에 이유를 적는다.
  - **확인할 시험**은 새로 넣거나 고칠 자동화 시험이다.
- 같은 브랜치에 새 커밋으로 한다. 반영한 항목의 상태를 `반영함 (<커밋 제목>)`으로 바꿔 같은 커밋에 넣는다. 커밋 본문에 보고 ①~⑤를 쓴다.
- AGENTS.md "일을 키우지 않는다"를 지킨다: 하위 에이전트 없이 혼자, 빌드·전체 시험은 끝에 한 번(최종 트리로).
- 판단이 필요하면 맨 아래 "질문"에 적고 멈춘다.
- push·`main` 머지는 하지 않는다. 끝나면 `HANDOFF.md`의 "Codex 결과"를 채운다.

### 1회차에 확인한 것

- **D1 상태:** 마지막 단계 뒤 `EnterStep`이 `EnterFreeMode(true)`로 넘어간다(`VBoRScenarioRunner.cpp:251-253`). 자유모드에서는 `StepIndex = INDEX_NONE`, generation +1, `bRunning` 거짓이다. 그래서 단계 규칙·확인·표지가 모두 꺼진다(`UpdateMarker`는 실행 중 단계에만). `IsFinished()`는 완료로 들어왔을 때만 참이다(`:267`). P3 E18("끝난 뒤 확인해도 generation 그대로", "안내 완료" 문구)은 그대로 통과한다.
- **"끝난 뒤 버림" 규칙 정리:** 예전 지난 단계 검사의 `bFinished && Action != Restart`를 뺐다(`:341`). 대신 자유모드 규칙이 단계 명령(확인·건너뛰기·이전·`End`·시점 단계)을 버린다(`:355-357`).
  - 완료 뒤 F5로 처음부터 돌아가는 중(기준 복귀 대기)에는 `bFinished` 참·`bFreeMode` 거짓·`bRunning` 거짓이다. 이때 명령은 "시작 전"으로 버린다(`:354`). 예전과 같다.
- **D2 `End`:** 실행 중에만 받는다. 시작 전·전환 중·자유모드에서는 버린다(E9, 시험 `FP5gGuardsTest`). 기록에 단계 ID와 요약이 남고, 건너뛰기 수와 따로 센다(`:263-271`).
- **D3·D4 좌석 버튼:**
  - 두 버튼을 다시 쓴다. 남은 두 좌석은 운전석 → 동승석 → 2열 순서다(`:559-576`).
  - 참가자의 동승석·2열은 자유모드에서만 받는다(`:344-346`). 순차 안내 중에는 지금처럼 권한으로 버린다(E11).
  - 패널을 다시 놓은 직후의 잠금은 넣을 때 표시하고(`:285-287`), 처리할 때 버린다(`:362-364`). 긴 dt로 처리해도 살아나지 않는다(E5).
  - 전환 중에는 정렬 컴포넌트가 추가 전환을 거부한다(E4·E6).
  - 버튼 이름표는 그 좌석 이름이다.
- **D5:** 자유모드에서 진행자 1·2·Home을 받는다(E7). F5는 지금 처음부터 규칙(문 초기화·기준 복귀)에 `bFreeMode = false`만 더했다(`:422`). 진행자 줄에 키가 보인다(E13).
- **D8 `F6`:**
  - 자유모드에서만 받는다(`:358-359`).
  - 받으면 `FadeSeconds`(0.3 s)로 검게 페이드하고, 다음 frame부터 dt를 빼서 0이 되면 지금 레벨을 한 번 연다(`:312-321`, `:386-393`). 요청한 frame의 dt는 세지 않는다.
  - 암전 중에는 모든 명령과 F1을 버린다(`:340`, `:626`).
  - 실제 레벨 이동은 가상 함수(`RequestLevelReload`, `:430-433`)로 빼서, 시험은 요청 횟수와 시점만 본다.
- **시험:** 실제 러너·근사 차·정렬 컴포넌트·ISDK poke 대리자·키 연결로 E1–E17을 돈다. 같은 frame의 참가자 버튼과 진행자 키는 전환을 한 번만 한다(요청 2·버림 1).
- **범위:** 부품·근사 차·시나리오 데이터·에셋은 바뀌지 않았다. 기존 시험 단언도 바뀌지 않았다(276 = 271 + 5). 주석은 사용자 말투다.
- **참고 — 고치지 않아도 됨:** `OpenLevel`이 실패하면(레벨 이름이 비었거나 이동 실패) 화면이 검은 채로 남고, 다시 열기 대기 때문에 모든 명령이 버려진다. `GetCurrentLevelName`은 게임·PIE에서 지금 맵 이름을 주므로 생길 일은 낮다. VR 확인(§7-6) 때 한 번 다시 열어 보는 것으로 충분하다.
- **리뷰어 메모:** 재현 빌드를 시작할 때 `UnrealEditor` 프로세스가 하나 떠 있었다. Codex 자동화가 끝나며 남은 것으로 보이고, 빌드 중에 종료됐다. 빌드는 DLL을 정상으로 덮어썼다. 전체 시험은 에디터가 꺼진 뒤에 돌렸다.
