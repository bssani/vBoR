- 항목의 세 칸은 이렇게 다룬다:

  - **확인할 시험**은 새로 넣거나 고칠 자동화 시험이다.
- 같은 브랜치에 새 커밋으로 한다. 반영한 항목의 상태를 `반영함 (<커밋 제목>)`으로 바꿔 같은 커밋에 넣는다. 커밋 본문에 보고 ①~⑤를 쓴다.

- push·`main` 머지는 하지 않는다. 끝나면 `HANDOFF.md`의 "Codex 결과"를 채운다.

### 1회차에 확인한 것

- **D1·D2:** 새 클래스 없이 `DetentNudgeDeg`(기본 0 = 끔) 하나와 `OnDetentNudge`(방향 +1/−1)를 더했다. 0이면 차선 변경 코드를 타지 않아 기어·P5b 16개가 그대로다(E12 — 기본값 0, 경고 없음, 걸림 알림 `{2,1,0}`). 검사는 `DetentProblem`에 음수·NaN·위/아래 기준 이상을 더했고 같은 경고·잡기 끔 경로를 탄다(E11 5종).
- **D3:** 확정 위치가 시작 걸림일 때만 본다. 절반 각도 이하(경계 포함)에서 무장하고, 차선 변경 각도 이상에서 1번 낸 뒤 무장을 푼다(E4: 4°는 다시 안 남, 3°·3.5°는 남). 다른 걸림에서 가운데로 들어오는 순간에는 그때 값이 절반 안일 때만 무장한다. 손으로 따라가 본 경우:
  - 상단에서 한 번에 −10° → 걸림(가운데)만, 차선 변경 없음. −3°를 거친 뒤 −7°면 그때 1번(E7)
  - 하단 → 상단을 한 번에 가로질러도 차선 변경 없음(가운데로 들어올 때 무장이 풀림)
  - 놓을 때·`BeginPlay`에서 무장(E10)
- **D4:** 차선 변경을 걸림 전환보다 먼저 대기열에 넣는다. 천천히·한 번에 모두 `N1 → D2` 순서다(E5).
- **D5:** 대기열이 `{종류, 값}` 구조체가 됐고, `Tick` 앞부분에서 순서대로 소리·이벤트를 낸다(P5b R1-1 방식 그대로). `Tick` 전에는 이벤트·소리 0(E1), 같은 frame 놓기 뒤에도 1번만(E8), 추적 손실·복구에서 버린 이동은 차선 변경을 내지 않는다(E9).
- **D6:** 차선 변경에도 딸깍 소리를 낸다(E1·E5). 위·아래를 왼쪽·오른쪽으로 이름 붙이지 않았다.
- **D7:** 축 (39, −44, 70), 16 × 2 × 2 cm, 차 −Y로 뻗음, `bReverse` 켬으로 값 + = 끝이 위. 옮기고 돌린 차에서 세 걸림 모두 왼쪽 앞 기둥·대시보드·핸들 판과 겹치지 않고, 기어 레버와도 3 × 3 조합 모두 겹치지 않는다(E13). `EndPlay`에서 정리한다(E14).
- **P2d E16:** 제외 목록에 `TurnSignalLever`만 더했다.
- **범위:** 깜빡임·좌우 이름·스티어링 자동 해제·끝 버튼은 없다. P3 단계 데이터·레벨·에셋은 그대로다. 주석은 사용자 말투(`~함`, 근거 ID)다.

## 참고 (항목 아님 — VR에서 볼 것)

- **차선 변경 7°는 레버 끝에서 약 2 cm다**(16 cm × sin 7°). 잡은 손이 떨려서 잘못 나는지, 반대로 너무 작아 일부러 내기 어려운지 본다(`TurnSignalNudgeDeg`).
- **차선 변경은 들어갈 때 1번만 난다**(사용자 문답 ①). 실차처럼 "누르고 있는 동안 깜빡이고 놓으면 멈춤"을 이벤트로 만들려면 "차선 변경 자리에서 나옴" 이벤트가 더 있어야 한다. VR에서 필요하면 그때 더한다.
- **두 레버가 축 기준 14 cm 떨어져 있다**(기어 축 Y −30, 방향지시 축 Y −44). 몸체는 서로 반대쪽으로 뻗지만, 한 레버를 잡으러 가는 손이 다른 레버를 먼저 잡지 않는지 본다(명세 §7-6).
- **자동화 로그 경로:** `-log=`에는 파일 이름만 준다(`Saved/Logs/` 아래에 생김). 경로를 줄 때는 `-abslog=`를 쓴다(엔진 `Runtime/Core/Private/GenericPlatform/GenericPlatformOutputDevices.cpp:86`). Codex가 이번에 겪었고, 머지 뒤 `Docs/Agent-Workflow.md` §2.4에 한 줄 더한다.
- 명세 §7 순서대로 본다: 시인성·도달 → 살짝 밀고 놓기 → 끝까지 → 끄기·지나침 → 각도 체감 → 기어와 헷갈림.
