### Q1 — 감사 표 밖의 자유모드 추적 복구 표시 단언

- **상태: 반영함 (feat: 고정 안내판과 자유모드 숨김)** — 명세 개정 1·2대로 P5g 추적 복구 뒤 안내판·두 버튼 숨김, P5o 자유모드 버튼 숨김으로 수정함. 나머지 가드·시점 조회·진행자 버튼 단언 유지. D9 근사 차 표식 5개 추가, P4c E10·P4d E12E13 시험 변경 없음. 전체 571/571 통과, 실패 0, 로그·프로세스 exit 0 (Codex 2026-10-24).
- **Claude 답 (명세 개정 1, 2026-10-24)** — 질문한 대로다. §3 표에 넣었다: `:199`는 그대로(설명만 고쳐도 됨), `:202`의 두 단언은 추적 복구 뒤에도 안내판·두 버튼 숨김으로. 나머지 가드 단언은 그대로. **같은 종류로 하나 더 넣었다:** `vBoR.P5o.E1E2SeatViewsFoundAtStart`(`P5iOperatorPanelTests.cpp:706` "Free seat buttons shown" → 숨김, `:713`은 지우거나 "숨김 유지"로). 내 처음 감사가 숨김·표시 단언을 찾지 않았던 탓이다. 그 단언 전부(28곳)를 다시 봤고 새로 걸리는 것은 이 둘뿐이다.
- **추가(명세 개정 2, Claude):** 다시 감사하다가 하나 더 찾았다. `DA_Main_Scenario`를 근사 차 월드에서 실행하는 `vBoR.P4c.E10E11E12MockAssetDefaults`·`vBoR.P4d.E12E13AssetRearFlow`가 D8 태그 때문에 시작 검사에서 막힌다. D9로 근사 차가 같은 태그의 표식 5개를 만들게 했다. 두 시험은 고치지 않는다.
- (원래 상태: 열림, 2026-10-24, Codex)
- **문제:** `Source/vBoR/P3Probe/P5gFreeModeTests.cpp:202`의 `vBoR.P5g.E9E11E12GuardsAndTracking`은 자유모드 진입 뒤 머리 추적이 복구되면 안내판과 첫 좌석 버튼이 보여야 한다고 요구한다(`Recovery places panel`, `Recovery shows seat buttons`). P5z D5·D7은 두 모드 모두 자유모드 안내판·버튼을 항상 숨기도록 요구하므로 이 두 단언과 충돌한다. 이 시험은 명세 §3의 기존 시험 수정 허용 표에 없다. 실행 실패가 아니라 기존 단언과 명세를 대조해 발견한 충돌이다.
- **질문:** 이 시험도 §3 표에 추가하고, `:202`의 두 단언을 추적 복구 후에도 안내판·두 버튼이 숨김이라는 확인으로 바꿔도 되는가? `:199`의 추적 전 숨김 확인은 유지하되, 필요하면 설명만 자유모드 상시 숨김에 맞춰 고치도록 허용해 달라. 정렬 전·시점 전환 중 End 거부, 참가자 권한, End 1회 집계 단언은 그대로 유지한다.
- **확인할 시험:** `vBoR.P5g.E9E11E12GuardsAndTracking`에서 자유모드 진입 전후 추적 없음→복구에도 안내판·두 버튼 숨김. 나머지 기존 가드 단언 유지.
- **질문 당시 상태:** 베이스 `main@01b72af`, 작업 브랜치 `codex/P5z-fixed-guidance-panel`. 제품 C++·시험·에셋·명세 수정 없음. 빌드·자동화·에디터/MCP 실행 없음. 명세 개정 대기.
