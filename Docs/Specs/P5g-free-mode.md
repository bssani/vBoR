## 0. 결정

| # | 결정 | 내용 |
|---|---|---|
| D1 | **흐름 상태에 자유모드를 더한다** | `AVBoRScenarioRunner`가 순차 안내 → **자유모드**로 넘어간다. 자유모드에서는 지금 단계가 없다. 순서 강제도 없고, 단계 규칙·확인·표지(바닥 고리·화살표)도 없다. 자유모드에서 빠져나가는 길은 진행자 처음부터(F5, 지금 규칙 그대로 `VBoRScenarioRunner.cpp:360-375`)와 레벨 다시 열기(F6, D8) 둘이다. 읽기 함수 `IsFreeMode()`를 더한다. `IsFinished()`는 지금 뜻(모든 단계를 마침)을 지킨다(`VBoRScenarioRunner.h:52`, P3 E18 `P3FlowTests.cpp:326-328`). 부품은 손대지 않는다 — 문·콘솔·실내 부품은 지금처럼 늘 켜져 있다(사용자 문답 ①) |
| D2 | **들어가는 길 두 가지** | ⓐ 마지막 단계를 마치면 바로 자유모드다(지금 `EnterStep`이 `bFinished`로 끝내는 자리, `VBoRScenarioRunner.cpp:246-249`). ⓑ **진행자 키 `End`**(새 명령)로 순차 안내 중 어느 단계에서든 바로 들어간다(리허설·시연). `End`는 안내가 돌고 있을 때만 받는다. 시작 전(정렬 필요 — O로 무시하고 시작해야 함), 시점 전환 중, 이미 자유모드일 때는 버리고 기록한다. ⓑ로 들어가면 `IsFinished()`는 거짓이고, 기록에 그때의 단계 번호를 남긴다 |
| D3 | **참가자 좌석 버튼** | 자유모드에서는 확인 버튼 대신 **지금 앉은 좌석을 뺀 두 좌석의 poke 버튼**(운전석·동승석·2열 중 둘)을 보인다. 운전석 = 기준 시점 복귀(`ReturnToBase`), 동승석·2열 = `Car.PassengerView`·`Car.RearView` 시점(지금 진행자 1·2와 같은 대상, `VBoRScenarioRunner.cpp:334`). 버튼 자리는 지금 두 버튼 자리(머리 앞 45 cm·아래 30 cm, 좌우 ±12 cm, `:400-404`)이고, 이름표는 좌석 이름이다. 누르면 같은 명령 경로(`QueueLive` → `Dispatch`)로 들어간다(AGENTS.md "입력 경로가 둘이어도 명령은 하나"). **자유모드에서만** 참가자의 동승석·2열 명령을 받는다. 순차 안내 중에는 지금처럼 진행자만 보낼 수 있다(`:315-316`) |
| D4 | **버튼을 숨기거나 버리는 때** | 시점 전환 중(암전)·패널 다시 놓기 대기 중에는 좌석 버튼을 숨긴다(지금 동작 버튼 규칙 `:500`과 같음). 패널을 다시 놓은 직후 잠금(`ConfirmLockSeconds`, `:406`) 동안 들어온 좌석 버튼 명령은 버린다. 좌석이 바뀌면 패널·버튼이 새 머리 앞으로 옮겨지는데(`:388-391`), 그 순간 손 아래에 버튼이 오면 바로 또 눌릴 수 있기 때문이다. 전환 중에 들어온 추가 전환(버튼·키)은 지금처럼 버린다(정렬 컴포넌트가 거부 `VBoRVehicleAlignmentComponent.cpp:97-103`, 흐름의 `TransitionDiscards`) |
| D5 | **자유모드의 진행자 키** | 1·2·Home(동승석·2열·운전석)은 자유모드에서도 받는다(지금은 끝난 뒤 버림 `:312`). F5는 처음부터(지금 규칙). F6은 레벨 다시 열기(D8). F1 정보는 그대로다. Space·←·→·`End`는 버리고 기록한다(단계가 없음). 진행자 줄 문구에 자유모드와 쓸 수 있는 키를 보인다 |
| D6 | **패널 문구** | 자유모드 문구는 편집 가능한 프로퍼티(FText)다. 예: "자유모드 — 차를 자유롭게 살펴보고 조작해 보세요. 좌석은 아래 버튼으로 바꿉니다". 마지막 단계를 마치고 들어오면 맨 앞에 지금 문구 "안내 완료"를 남긴다(P3 E18 단언 유지). 진행자 키로 들어오면 "안내 완료" 없이 자유모드 문구만 보인다 |
| D7 | **기록** | 들어갈 때 "자유모드 시작 — 안내 완료" 또는 "자유모드 시작 — 진행자 End, 단계 <ID> 에서"와 지금 요약(이전·재시도·건너뛰기·버림 수, `:248`)을 남긴다. 좌석 명령은 지금 `LastViewRequest` 기록을 그대로 쓴다(참가자·진행자 구분). 진행자 `End`는 건너뛰기 수에 더하지 않고 따로 센다 |
| D8 | **끝나면 레벨 다시 열기(진행자 `F6`, 자유모드에서만)** | 다음 참가자를 위해 지금 레벨을 처음부터 다시 연다(`UGameplayStatics::OpenLevel` + `GetCurrentLevelName`, 엔진 `Runtime/Engine/Classes/Kismet/GameplayStatics.h:341`, `:359`). **부품마다 되돌리는 함수를 만들지 않는다.** 문·실내 부품·키·박스·리프트게이트·흐름 상태가 모두 처음 상태로 돌아오고, 테스트한 부품 클래스는 바뀌지 않는다. **운전석 복귀는 따로 하지 않는다.** 레벨이 시작될 때 정렬 컴포넌트가 저장된 Buck 정렬을 읽어 Pawn을 기준(운전석) 자리에 놓는다(`Interaction/VBoRVehicleAlignmentComponent.cpp:22-33`, `:62-65`; P0-c VR 확인 "재시작 자동 적용"). 다시 연 뒤에는 01번부터다. 바로 자유모드가 필요하면 `End`. **자유모드에서만 받는다** — 순차 안내 중 실수로 눌러 평가가 처음으로 돌아가지 않게 한다(순차 안내 중 처음부터는 지금 F5). 다시 열기 전에 좌석 전환과 같은 암전(`FadeSeconds` 0.3 s, `VBoRVehicleAlignmentComponent.h:33`, 페이드 `.cpp:107`)을 한 번 하고, 화면이 검게 된 뒤에 연다(멈춘 장면이 헤드셋에 보이지 않게). 암전 중에 다시 누른 F6·다른 명령은 버린다(한 번만 연다). 정렬을 무시하고(O) 시작한 경우, 다시 연 뒤에도 다시 O가 필요하다(지금 규칙) |

## 1. 왜 만드는가

- 계획서 흐름의 끝(마지막 단계 → 자유모드, U-01)이 아직 없다. 지금은 "안내 완료"에서 멈추고, 진행자 시점 키까지 버린다(`VBoRScenarioRunner.cpp:312`).
- P5에서 만든 실내 부품(글러브박스·기어·방향지시·휠·룸미러·노브)을 자유모드에서 다시 쓰려면, 참가자가 운전석·동승석·2열을 오가며 볼 수 있어야 한다.

## 3. 지켜야 할 조건 (바꾸면 안 되는 것)

- 기존 `vBoR.*`가 모두 그대로 통과한다. 특히 P3 흐름(E1–E19)과 P2b의 08 완료(`P2bAxisPartTests.cpp:410`). 기존 단언은 바꾸지 않는다.
- 순차 안내 중의 동작은 그대로다: 권한(참가자는 확인·시점·운전석만), 확인 잠금, 지난 단계 명령 버림, 한 frame에 여러 단계를 넘지 않음, 처음부터의 문 초기화.
- 좌석 전환은 지금 정렬 컴포넌트의 고정 시점·암전 전환만 쓴다. 자유 텔레포트를 만들지 않는다.
- 같은 명령이 손(좌석 버튼)과 키보드로 같이 들어와도 전환은 한 번이다. 전환 중의 추가 전환은 버린다.
- 진행자 대리 조작과 참가자 수행을 구분해 기록한다.

- 좌석 버튼을 지금 두 버튼(`ConfirmButton`·`ActionButton`)을 자유모드에서 바꿔 쓸지, 새로 만들지. 바꿔 쓰면 버튼 수와 자리를 그대로 지킬 수 있다(권장). 어느 쪽이든 순차 안내 중의 버튼 동작은 그대로다.
- 두 좌석 버튼의 좌우 순서(예: 운전석 → 동승석 → 2열 순서에서 지금 좌석을 뺀 둘).
- 자유모드 문구의 기본값(D6 예시에서 출발).
- 레벨 다시 열기 요청을 시험에서 바꿔 낄 수 있게 가상 함수로 뺄지(권장 — 자동화의 임시 world에서는 실제로 레벨을 옮길 수 없어, 시험은 요청 횟수·시점만 본다).
- 암전을 정렬 컴포넌트의 카메라 페이드로 할지, 러너에서 직접 할지. 어느 쪽이든 길이는 `FadeSeconds`를 따른다.
