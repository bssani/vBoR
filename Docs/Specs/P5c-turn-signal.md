## 0. 결정

## 1. 왜 만드는가

- 자유모드(P5)의 실내 조작 목록(U-09·U-11)에 방향지시 레버가 있다. 평가 단계(01–20)에는 넣지 않는다.
- 기어와 같은 세 걸림이지만, 가운데에서 살짝 밀었다 놓는 차선 변경 신호가 따로 있다.

## 3. 지켜야 할 조건 (바꾸면 안 되는 것)

- 기존 `vBoR.*`가 모두 그대로 통과한다. 특히 P5b 기어 16개(차선 변경 0 = 끔이라 동작이 같아야 한다), P2b 1축 부품, P2c·P2d 문 손잡이, P5a 글러브박스.
- `Return`·`Stay` 부품과 차선 변경이 꺼진 걸림 부품의 동작·이벤트는 지금과 같다.
- P5b R1-1을 지킨다: 사용자 이벤트·소리는 ISDK 포인터 `Move` 처리 밖(`Tick`)에서만 낸다. 확정·판정은 바로 한다(같은 frame 놓기).
- "추적 손실은 보류"를 지킨다: 보류 중·복구 때 버린 손 이동으로 이벤트가 나지 않는다.
- 차 원점 피벗 보정을 지킨다: 레버 Actor 원점 = 차 원점, 쉬는 메시 = 원래 world 자리.
- 근사 차의 기존 부품(기어·끝 버튼 포함) 자리와 동작은 그대로다.
- 근사 형상임을 드러낸다(이름·주석·로그).

## 5. 구현자가 정할 것

- 프로퍼티·이벤트 이름과 분류(차선 변경은 "Axis part\|Detent" 아래 권장). 이벤트 인자는 방향(+1 / −1) 필수.
- 대기열에 종류를 담는 방식(D5).
- 재무장 각도는 차선 변경 각도의 절반으로 고정한다(새 프로퍼티를 만들지 않음).
- 경고 문구.
- 근사 차 프로퍼티 이름과 값(D7 예시는 출발점). 회전 부호는 시험으로 "값 + = 끝이 위로"를 보인다.
