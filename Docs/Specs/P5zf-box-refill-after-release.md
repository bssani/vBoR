## 1. 왜 하는가

박스를 든 채 받침대 근처에서 걸리면, 걸린 박스 바로 옆에 새 박스가 생겨 든 박스를 막는다. 시간 지연(몇 초 뒤 생성)은 받침대 근처에 그보다 오래 머물면 같은 일이 생겨서 택하지 않았다. 놓은 뒤에 만들면 손에 든 박스는 새 박스와 만날 수 없다. 하나를 싣는 동안 받침대가 비어 있고, 싣고 나면 다음 박스가 생긴다.

## 3. 지켜야 할 조건 (바꾸면 안 되는 것)

- 박스를 놓은 뒤의 동작은 지금과 같다: 놓은 박스가 자리에서 벗어나 있으면 다음 받침대 Tick에 한 개, 자리에 걸치면 없음.
- 첫 박스(BeginPlay), `ResetStand`, `EndPlay`, 바닥 제거, 박스 클래스·크기·자리는 그대로.
- **기존 시험 감사(Claude 2026-10-28, `BoxStand`·`SourceBox` 검색).**
  - **고쳐도 되는 단언(들고 있는 채로 채워지기를 기대함):**
    - `P3Probe/P3FlowTests.cpp` `vBoR.P4d.E6E7SupplyFloorResetCleanup` `:1211-1216` — 잡은 채 40 cm 들고 일시정지 해제 → 2개를 기대. 새 규칙에서는 1개다. **놓은 뒤에 2개**가 되도록 순서를 바꾼다(놓기 `FP4dTestAccess::Release`). `:1206-1210`(잡기만·겹침·1 cm 경계·일시정지)은 결과가 같으니 그대로 둔다. E7 부분(바닥 제거·리셋·EndPlay `:1214-1220`)은 의미를 지키며 순서에 맞게 고친다.
    - `P3Probe/P5tBoxBlueprintTests.cpp` `vBoR.P5t.E4ClassSizeSupplySlot` `:131-138` — 잡은 채 50 cm 들기 → 2개를 기대. **놓은 뒤에** 2개, 원래 자리, 중복 없음으로 바꾼다. 40 + 1 cm 경계(`:132-133`)는 놓은 상태에서도 확인한다(클래스 크기로 자리를 정한다는 P5t 의도).
  - **바뀌지 않아야 하는 시험:** `vBoR.P4d.E1E10RearAssemblyAndRoutes`(첫 박스), `vBoR.P4d.E4ClosedAndObstruction`(잡지 않고 옮김 — D3), `vBoR.P4d.E8E9Restart`(잡고 옮기고 놓은 뒤 채움 `:1234-1236` — 이미 놓음), `vBoR.P5t.E3`·`E5`·`E8`, `P4iCarBlueprintTests`. **위 두 곳 밖을 고쳐야 통과하면 멈추고 리뷰 파일 "질문"에 적는다.**

## 4. 시험 — `vBoR.P5zf.*`

받침대 시험은 `P5tBoxBlueprintTests.cpp`의 `FP5tWorld::Stand`처럼 받침대를 만들고 Play한다(근사 차 불필요). 잡기·놓기·일시정지는 기존 시험 접근(`BeginCarry`·`ReleaseCarry`·일시정지 주입, `FP4dTestAccess`·`FP5tTestAccess` 참고)으로 한다.

| ID | 상황 | 확인 |
|---|---|---|
| E1 | 원래 박스를 잡고 자리에서 50 cm 들어 올림, 받침대 Tick 여러 번 | 박스 1개(새 박스 없음) |
| E2 | E1 뒤 놓음(자리 밖), 받침대 Tick | 2개, 새 박스는 `StartPose`, 다음 Tick에도 2개 |
| E3 | **걸림 재현:** 잡고 자리 경계 바로 밖(자리 + 2 cm)에 둔 채 Tick 여러 번 | 1개. 놓은 뒤 Tick → 2개 |
| E4 | 잡고 들어 올린 뒤 추적 손실 일시정지, Tick → 복구(아직 잡음), Tick | 둘 다 1개 |
| E5 | 두 손으로 잡고 들어 올림, Tick → 한 손 놓음(한 손 남음), Tick → 마저 놓음, Tick | 1 → 1 → 2 |
| E6 | 들어 올렸다가 받침대 자리 안에 다시 놓음, Tick | 1개(D2) |
| E7 | 놓아 트렁크(적재 영역)에 있는 박스를 다시 잡음 — 받침대에는 새 박스가 이미 있음 | 다시 잡고 옮겨도 받침대 박스 수 변화 없음(새 박스는 자리에 있으므로) |
| E8 | 놓은 박스가 바닥에 떨어져 제거됨 | 다음 Tick에 받침대 박스 1개(자리에 새 박스) |

- 박스 수는 받침대가 owner인 `AVBoRCarryObject` 수로 센다(`P4dBoxes`·`P5tBoxes`와 같음).
