## 1. 왜 만드는가

- 16 "시트 폴딩 각도를 확인하세요"에 쓸 시트가 근사 차에 없다. 사용자는 참가자 조작 없이 진행자가 접어 보이기를 원한다(U-15). 자유모드에서 보는 기능이다(사용자 ③).
- 실제 차 데이터가 오면 등받이 CAD를 자식 BP에 넣어 같은 버튼으로 쓴다.
- P4d에서 넘긴 작은 빈틈(D7)을 같은 흐름 파일을 고치는 김에 닫는다.

## 2. 범위

### 만들 것

1. `AVBoRFoldingSeat`(D1).
2. 근사 차 2열 좌석(D2).
3. 진행자 창 버튼·키·명령·판정(D3·D4), R(D5).
4. 경로 위 화살표 갱신(D7).

## 3. 지켜야 할 조건 (바꾸면 안 되는 것)

- 기존 진행자 버튼·키·명령의 순서와 동작은 그대로다(enum은 끝에 붙임). 버튼 이름이 칸에 맞아야 한다(`vBoR.P5i.E23SlateTextFits`).
- 진행자 창의 주 버튼(Primary)은 지금처럼 하나다(`vBoR.P5i.E21ButtonStyles`). 새 버튼은 Secondary다.
- 2열 시점 자리와 기존 근사 차 부품·경로·트렁크는 그대로다.
- 단계 규칙·에셋·생성자 기본 단계·TV 기본표는 그대로다.
- D7 밖의 경로 동작(모를 때 다시 읽기, 알림 한 번 기록, "밖"은 다시 안 읽음 — P4d E11)은 그대로다.
- 기존 단언은 바꾸지 않는다.
