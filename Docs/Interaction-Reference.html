INT-001 · 외부 도어 손잡이

당김 방향 가설 · 놓으면 복귀

사진 관찰 · C-01, C-02 길게 휘어진 몸체, 오목한 안쪽 윤곽과 손가락 공간, 넓고 둥근 끝부분, 끝부분을 나누는 굽은 이음선이 보입니다. 두 사진의 시점을 유지합니다.

이전 사용자 가설 “당겨지고 왼쪽 기점으로 오른쪽이 살짝 당겨지겠지?” 왼쪽을 중심으로 오른쪽 끝이 문 바깥쪽으로 나오는 동작을 가정합니다. 사진에서 실제 회전축을 확인한 것은 아닙니다.

이번 사용자 번호 1·2 = C-01·02 = 외부 doorhandle입니다. 기존 사진 1·2의 실내 손잡이 설명을 이 부품에 적용하지 않습니다. B-01과 같은 원본 파일인지는 미확인입니다.

사용자 설명·추가 답변: 문을 연 뒤 손잡이를 놓으면 원래 위치로 돌아옵니다. 손잡이 복귀이지 문 자체의 자동 닫힘을 뜻하지 않습니다.

이전 AI 가정 · 미확정: 오른쪽 커버 고정. 이음선만으로 끝부분의 고정 여부를 확정하지 않습니다. 복귀는 이제 사용자 설명이며 AI 가정에서 제외합니다.

미정: 실제 회전축, 이음선 양쪽의 가동 범위, 문 열림 시점, 각도·치수, 복귀 속도. 당김 방향 가설과 놓으면 복귀하는 요구를 구분합니다.

원본의 두 시점과 작동 가설

형상 수정안이며 사용자 일치 확인은 아직 받지 않았습니다. 체크무늬 재질·조명·작동 각도를 재현한 그림은 아닙니다.

INT-002 · 실내 도어 손잡이

기존 1, 2 / C-03 / 새 E-01·02

대각선 쪽을 잡고 위로 올리면 차 문이 열립니다. 놓으면 손잡이는 원래 위치로 돌아옵니다. 손잡이 복귀이지 문 자체의 자동 닫힘은 아닙니다. 실제 이동축·각도·복귀 속도는 미정입니다.

INT-003 · 선바이저

기존 3 / C-04 / 새 E-03·04

윗부분을 손으로 잡고 아래로 내립니다. 다시 위로 올리면 접힙니다. 잠금 없이 내리고 올릴 수 있습니다.

INT-004 · 룸미러 (백미러)

기존 4, 5 / C-05·06 / 새 E-05·06

위·아래·왼쪽·오른쪽을 밀면 그 방향으로 각도가 바뀝니다. pinch 또는 grab으로 잡으면 상하·좌우를 조합한 방향으로 조절할 수 있어야 합니다. 위치 이동이 아니라 보는 방향의 변화입니다.

INT-005 · 콘솔박스

기존 6, 7 / C-07·08 / 새 E-07·12

열기는 두 방식 중 하나로 가능합니다. 앞쪽 손잡이의 누르는 부분을 여기서는 버튼으로 기록합니다.

  • 열기 A: 버튼을 누른 상태로 유지하면서 뚜껑을 직접 들어 올립니다. 누른 뒤 손을 떼고 올리는 순서가 아닙니다.
  • 열기 B: 버튼 없이 뚜껑을 grab해서 들어 올립니다. grab 대상은 앞쪽 손잡이가 아니라 뚜껑입니다.
  • 닫기: 열린 상태에서만 위에서 손바닥으로 눌러 내려 닫습니다. 닫힌 상태에서의 손바닥 누름은 반응하지 않으며, 두 열기 방식은 여전히 가능합니다.
  • 복귀: 버튼을 놓으면 버튼 자체가 원래 위치로 돌아옵니다. 뚜껑의 자동 닫힘을 뜻하지 않습니다.

INT-006 · 글러브박스

기존 8 / C-09·10 / 새 E-08·13
  1. 손잡이를 위로 올립니다.
  2. 손잡이를 열면 문이 아래쪽으로 내려가며 열립니다.
  3. 열린 문을 밑에서 손바닥으로 밀어 올리면 닫힙니다.
  4. 닫혀 잠기면 아래로 내려가지 않습니다. 다시 열려면 손잡이를 먼저 올려야 합니다.

놓으면 손잡이는 원래 위치로 돌아옵니다. 손잡이 복귀이지 문 자체의 자동 닫힘은 아닙니다. 복귀 속도는 미정입니다.

INT-007 · 스티어링 휠

기존 9 / C-16 / 새 E-09

한 손으로도, 양손으로도 돌릴 수 있어야 합니다. 좌우로 돌리되 정해진 한계에서 멈추고 끝없이 돌아가지 않습니다. 최대 회전 각도는 아직 정하지 않았습니다.

INT-008 · 기어 레버와 버튼

기존 10 / C-11·12 / 새 E-10·14

위치는 상단·중단·하단의 3개이며 시작 위치는 중단입니다. 현재 머무는 위치에서 위 또는 아래로 밀어 설정한 전환 기준 각도 이상 움직이면 해당 방향의 인접 위치로 갑니다.

일반적인 기어 레버처럼 손을 떼지 않고 계속 밀면 중단을 거쳐 연속 이동합니다. 아래로는 상단 → 중단 → 하단, 위로는 하단 → 중단 → 상단으로 각 전환 기준에 도달할 때 이어서 이동합니다. 중단에서 손을 놓거나 다시 잡을 필요는 없습니다.

위쪽·아래쪽 전환 기준 각도를 각각 정할 수 있어야 합니다. 15°는 사용자 예시이지 확정 설정값이 아닙니다. 현재 설정값은 미정이며, 전환 기준은 각 위치 자체의 각도·전체 이동 한계와 구분합니다.

현재 위치미는 방향전환 기준이동 결과
중단위위쪽 기준 이상 (예시 15°)상단
상단아래아래쪽 기준 이상 (예시 15°)중단
중단아래아래쪽 기준 이상 (예시 15°)하단
하단위위쪽 기준 이상 (예시 15°)중단

다음 전환의 기준 미만에서 놓으면 마지막으로 확정된 위치로 복귀합니다. 기준에 도달해 전환한 뒤 놓으면 새 위치를 유지합니다. 항상 중단으로 자동 복귀하는 동작이 아닙니다.

레버 버튼은 누를 수 있어야 하지만 역할·이동과의 관계는 미정입니다. 실제 이동축·세 위치의 각도·전체 이동 한계, 상단에서 더 위로 또는 하단에서 더 아래로 미는 입력도 미정입니다. P/R/N/D 등의 기능은 연결하지 않습니다.

INT-010 · 콘솔 앞 노브

기존 12, 13 / C-14·15 / 새 E-15 · 후보 유지

사진의 측면 요철을 잡고 돌리는 동작을 두 가지 후보로 기록합니다. 엄지·검지로 테두리를 잡는 방법을 먼저 검토하고, 손으로 감싸 잡는 방법과 비교할 수 있습니다. 아직 채택한 방식은 아닙니다.

INT-011 · 리프트게이트

D-01~03 · 전체 형상 / 열기 / 닫기

열기 버튼을 누르면 위로 올라갑니다. 올라간 상태에서 내려가는 버튼을 누르면 아래로 내려옵니다. 손으로 직접 들어 올리거나 내리는 동작이 아니라 버튼으로 여닫는 동작입니다.

사진 관찰 넓고 휘어진 게이트 하단, 안쪽 트림의 여러 단차, 원형 하우징과 그 옆의 가로 직사각형 버튼, 더 오른쪽의 큰 패널, 아래쪽 작은 버튼과 깊은 손잡이 홈, 중앙의 갈라진 돌출부를 각 사진 시점에 맞춰 그렸습니다.

이번 사진 1~3을 D-01~03으로 구분합니다. 사용자가 사진 2를 열기 버튼, 사진 3을 닫기 버튼으로 명시했습니다. 기능 연결은 모양에서 추측한 것이 아니라 사용자 명칭에 근거합니다. 기존 B 연결은 보존하며 동일 파일인지는 미확인입니다.

사진과 사용자 설명을 분리합니다. 원형 부분의 기능은 미정입니다. 사진 속 선택 테두리·편집기 이동축은 차량 부품이 아니므로 도해에서 제외했습니다. 사진 3에서 선택 표시가 가린 부분의 정확한 형상은 미확인입니다.

미정: 이동 중 재입력, 자동 복귀, 실제 열림 각도·치수. C-17의 누름·복귀 설명은 이 부품에 적용하지 않습니다.

외부 손잡이와 같은 형상 도해 방식으로 수정한 초안입니다. 실제 치수·체크무늬·가려진 면의 재현이나 사용자 일치 승인을 뜻하지 않습니다.
